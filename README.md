## 🎯 Resumo do Projeto
Este projeto é a culminância da formação acadêmica em Ciência de Dados para Negócios, estruturado como um **Portfólio Digital** que integra as competências adquiridas nos seis semestres da graduação. 

---

## 🛠️ Pilares de Desenvolvimento (Interdisciplinaridade)
O desenvolvimento seguiu o tripé fundamental estabelecido no PPC do curso:
**Conhecimento de Negócio (Business):** Alinhamento estratégico, análise de processos e viabilidade econômica.
**Ciência da Computação (Machine Learning):** Implementação de algoritmos e automação de pipelines de dados.
**Matemática e Estatística:** Aplicação de modelos estatísticos e otimização para suporte à decisão.
